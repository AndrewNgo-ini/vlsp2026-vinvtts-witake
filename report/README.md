# Technical report (VLSP 2026 ViNV-TTS, team WiTake)

`main.pdf` is the report (ACL template). Build: `tectonic -X compile main.tex` (or `pdflatex main && bibtex main && pdflatex main && pdflatex main`).
Every number in it comes from our development logs (HF `trivitaai/vlsp2026-vinvtts-sprint`, `reports/`) or from
`vinvtts/offscore.py` on the public-test outputs of the submitted system (`public_final_v5_levelling/`); the NV
loudness-levelling numbers come from the levelling logs (`ar_uncanny_1001/`).
